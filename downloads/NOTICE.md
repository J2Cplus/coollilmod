# Downloads withdrawn

Windows Defender reports identified both LunaBuilder-Windows.zip and LunaBuilder-all-in-one.jar as Trojan:Script/Wacatac.B!ml. All current binary downloads have been withdrawn pending investigation. Do not run these builds, allow the detection, or add antivirus exclusions. The cause has not been established; no false-positive claim is being made.

The source remains available for audit. Earlier binaries may still exist in Git history or on users' machines; withdrawal of current links does not make those copies safe. No replacement build is currently endorsed.

The all-in-one JAR bundles a Windows Node executable, companion JavaScript and Java background-process startup code. The old Windows ZIP also includes PowerShell/CMD startup scripts. Matching an official runtime checksum does not establish the complete bundle is safe. Re-sharing a historical build does not clear the detection. No replacement has been security-verified.
