# Downloads withdrawn

A Windows Defender report classified LunaBuilder-Windows.zip as a severe Trojan. All current binary downloads have been withdrawn pending investigation. Do not run these builds, allow the detection, or add antivirus exclusions. The cause has not been established; no false-positive claim is being made.

The source remains available for audit. Earlier binaries may still exist in Git history or on users' machines; withdrawal of current links does not make those copies safe. No replacement build is currently endorsed.
